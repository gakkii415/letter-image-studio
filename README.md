# 文字画像作成Webアプリ

タトゥーなどのレタリングを複数書体で比較し、横書き・縦書きを白背景PNGに保存するブラウザアプリです。メイン画面はスクロールせず、入力・プレビュー・調整・保存を一画面で操作します。

## 使い方

1. 下部の文字入力欄に入力し、比較する書体を選択します。
2. 字間・行間をスライダー・数値・±で調整します。色は表示されたパレットから選び、「その他」で自由に指定できます。変更はその場で反映されます。
3. 「画像を保存」で共有画面を開き、iPhoneでは「画像を保存」を選ぶと写真へ保存できます。共有に対応しない環境では画像の長押し保存かダウンロードを使います。

プレビューはドラッグで移動、ピンチで拡大縮小できます。「全体」で画像全体に戻ります。保存用PNGは操作が止まってから準備します。

既定は游明朝体とヒラギノ角ゴ W3です。端末にない場合は代替書体を明示します。フリーフォントのアプリ内追加、フォントファイル・対応する直接URLの読み込みに対応します。

文字サイズは全書体・縦横で共通とし、内容に合わせて画像サイズを調整します。前後の空行は画像の余白に含めず、途中の改行・空行は反映します。入力は160文字、同時選択は8書体までです。極端に改行が多く読みやすさを保てない場合は、設定変更を案内します。

入力と設定はlocalStorage、追加フォントはIndexedDBに保存します。ブラウザデータを消去すると消えます。入力や追加したフォントはサーバーへ送信しません。

## 開発

ビルド不要。`python3 -m http.server 8000` で表示し、`npm test` で文字分割・折り返し・画像寸法を検証します。ブラウザー回帰テストは `npm ci`、`npx playwright install --with-deps chromium webkit` の後に `npm run test:browser` で実行できます。

フォントはOFLで配布される英字6種類・日本語4種類です。出典・ライセンスは `assets/fonts/` にあります。再生成には `.github/build-font-assets.py` を使います。

変更前のSHAを控え、反映前に `.github/mandatory.py --base <開始前SHA> --fix` と同じSHAでの通常検査を実行してください。
